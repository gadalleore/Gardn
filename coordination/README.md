# Coordination

One file per track. **Edit only your own track's file.** Keep it short and
current: what you're doing right now, which files you're touching, and anything
another track or the human needs to know. This is a snapshot for whoever pulls
next — not live chat (see `../CLAUDE.md`).

If you need something from another track or a change to a shared contract
(`../docs/module-contracts.md`), write it under **Needs / requests** below and
flag the human — don't reach into their files.

Tracks: `terrain`, `weather`, `trees`, `foliage-life`, `sprites`.
